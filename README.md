# **摘要**

　　地表温度是城市热环境分析、地表过程研究、地热调查前期筛查、农田温度监测、林火识别与监控等应用场景的重要数据，但常用热红外产品的空间分辨率难以直接刻画街区尺度的温度差异。GeoThermoAI 将 Landsat 地表温度、Sentinel-2 多光谱影像和 Copernicus DEM 组织为一条可交互的 10m 地表温度空间降尺度流程。

　　GeoThermoAI的核心特色是多角色 Agent 与确定性遥感算法的结合。Agent 负责理解用户目标、组织任务、检查数据质量、控制执行节奏和解释结果。定标、掩膜、空间划分、模型训练、热约束校正和精度计算仍由明确的地学规则完成。用户既可以在 Chat 模式中理解方法原理，也可以在 Work 模式中审批方案并运行完整流程。

　　地表温度降尺度工作流通常包含数据下载、数据预处理、模型训练、地表温度结果生成等步骤，具备较高的操作门槛，尤其是对于城乡规划从业者等非遥感出身但对地表温度产品有需求的群体而言。因此我们将Agent能力融入地表温度降尺度工作流，希望能大大提升高分辨率地表温度产品生产的智能化程度并大大降低门槛，提升科研以及生产场景的工作效率。GeoThermoAI 是一次将 Agent 融入专业遥感工作流的重要尝试，我们希望以 GeoThermoAI 为例，借助 LLM 和 Agent 对自然语言指令的处理能力，将原先专业化的遥感工作流推向大众化应用的广阔空间。

# **一、背景与动机**

## **1.1 从遥感影像到可用温度产品的四个断点**

### **1.1.1 空间分辨率不足**

　　Landsat 热红外产品能够提供稳定的地表温度参考，但其空间尺度（原始分辨率为 100m，USGS官方地表温度产品将其重采样至与多光谱一致的 30m ）难以充分表达道路、水体、建筑密集区和植被斑块之间的细微差异。简单重采样只能保证在大致温度范围不变的情况下增加像元数量，不能恢复真实可信的空间细节。图 1 - 图 3 展示了 10m 高分辨率地表温度影像的几大应用场景与优势。

### **1.1.2 多源数据难以直接协同**

　　热红外、多光谱和地形数据在成像日期、坐标系统、分辨率、质量标识和无效值规则上均有差异。任何一个环节处理不当，都可能把云、阴影、边界空洞或定标误差带入模型。

### **1.1.3 细节增强与温度约束难以兼顾**

　　高分辨率光学影像可以提供细尺度纹理，但纹理并不等于温度。降尺度结果既要体现地表覆盖和地形差异，又要避免偏离原始热红外观测所提供的粗尺度温度约束。

### **1.1.4 专业流程对非专业用户不够友好**

　　传统遥感工作流往往需要用户掌握数据检索、投影转换、质量控制、模型训练和栅格输出。但地表温度产品的很多使用者，如规划农田建设的农业从业者、根据地表热力情况进行城市通风廊道规划的城市规划师等，并非遥感专业出身，不熟悉地表温度产品生产流程与技术细节，而当前鲜有 10m 高分辨率的地表温度产品公开发布，需要一款简单易用的软件便于生产场景的非专业用户的使用。GeoThermoAI 将这些环节组织为可解释的阶段任务，使用户能够用自然语言描述需求，并在关键节点查看和批准方案。

## **1.2 科学价值与应用边界**

　　GeoThermoAI 的科学价值在于把多源遥感特征、地形热响应和粗尺度热约束放在同一流程中处理。它输出的是由 30m 热参考约束的 10m 温度估计，可用于观察空间异质性和识别值得进一步调查的区域。

　　需要强调的是，降尺度结果不是独立获取的 10m 热红外观测。在缺少同期高分辨率温度真值时，模型评估回答的是对留出 30m 温度样本的预测能力，粗尺度闭合回答的是结果回聚合后能否恢复约束均值。这两个问题不能替代独立的 10m 精度验证。

# **二、项目定位与整体架构**

## **2.1 项目定位**

　　GeoThermoAI 是面向地表温度空间降尺度的交互式 GeoAI 系统。完整任务包括数据获取、数据预处理、地形热响应计算、模型训练、热约束校正、温度产品导出和精度评估。用户还可以在需要连续表面时选择空洞填补。

　　理解本项目时，需要区分“参考”“估计”和“验证”三个层次。Landsat 经质量控制后的 30m 地表温度提供粗尺度热参考，但不是 10m 真值。随机森林先利用光谱和地形信息生成 10m 初始温度，热约束校正再使同一 30m 父格内的有效子像元均值回到参考温度，形成最终产品。这一约束保持的是父格算术均值，不代表能量守恒。

　　精度评价也分为两个问题。空间分块留出测试检查模型对未参与训练的 30m 样本的预测能力，粗尺度闭合检查最终结果回聚合后能否恢复参考均值。两者都不能替代同期独立 10m 温度观测。可选的空洞填补仅用于获得连续显示表面，不被当作新增观测，也不进入主要精度结论。

# **三、系统特色与重要功能**

## **3.1 面向连续任务的记忆系统**

　　GeoThermoAI 不把每次对话视为彼此孤立的请求。系统以项目和对话为边界保存已确认的研究区、时间条件、用户偏好、执行方案和实验结果，使用户再次进入同一项目时能够继续已有任务，而不必重复说明全部背景。

　　记忆内容分为三个层次。对话记忆保存当前任务意图、已确认条件、待补充信息和用户批准状态。项目记忆积累历史实验、结果指标、数据组合和可复用流程。领域记忆提供地表温度、遥感数据质量、模型训练与结果评价相关知识。系统根据当前角色检索不同内容，例如 Data 角色优先关注数据与质量控制，Train 角色优先参考模型经验，Evaluation 角色优先调用评价知识。只有通过评价的成功流程才会进入可复用经验，使后续任务能够借鉴历史结果，同时保留用户重新选择参数和数据的权利。

　　GeoThermoAI 采用**精确查询 + RAG 语义检索双轨制**：写入时双写（JSON 结构化记录 + ChromaDB 向量段落），读取时四段叠加注入 prompt——领域知识 RAG、项目经验 RAG、历史最佳实验（按 R² 精确排序）、以及从用户 query 正则提取 region/时间/影像对日期后的结构化精确匹配。RAG 用 bge-small-zh-v1.5 ONNX 嵌入 + cosine 相似度负责"语义相关"，JSON 精确查询负责"指标可溯源"，两者按角色（planner/data/train/eval）定制检索范围和条数，RAG 失败时有多级兜底（无过滤查询 → 精选种子条目）。核心思路是**语义检索找相关、精确查询对指标**，避免单纯 RAG 在需要精确字段匹配的场景下不命中。

## **3.3 Chat 与 Work 双模式可选**

　　此功能的设计灵感来源于 ChatGPT 桌面端当前的“聊天”“工作”双模式以及 Qoder Desktop 编辑器模式下的“智能问答”“智能体”双模式，旨在为不同对话任务划定执行边界，确保任务针对性与可控性。

### **3.3.1 Chat 模式**

　　Chat 用于解释算法、参数、指标和结果边界。它不会启动数据下载或修改结果，适合用户在运行前了解方法，在运行后询问温度值和精度含义。

### **3.3.2 Work 模式**

　　Work 用于执行完整任务。系统先形成方案，再依次完成数据获取、预处理、地形热响应计算、模型训练、热约束校正、产品导出和精度评价。界面同步展示当前阶段、运行状态和结果入口。

## **3.4 “由我批准”与“完全执行”双模式可选**

　　此功能设计的设计灵感来源于 ChatGPT 桌面端的“请求批准”“帮我批准”“完全访问”三种模式。“由我批准”与“完全执行”双模式是面向工作流处理的，因而仅在 Work 模式下可选。

### **3.4.1 由我批准模式**

　　“由我批准”适合希望控制过程的用户。系统会在方案确认和关键选择处暂停（如影像配对的选择、超参数寻优等节点），用户可以接受推荐，也可以调整研究区、时间、数据组合或模型参数。

### **3.4.2 完全执行模式**

　　“完全执行”适合参数已经明确的任务。系统按照既定规则连续完成各阶段（包括自动选择并下载最合适的影像与 LLM + 规则约束的智能调优等），如果数据不完整或质量不足时会自动停止，不以占位影像替代缺失数据。完全执行与由我批准模式模式共享相同的遥感处理与评价标准，区别只在于人工介入程度，完全执行模式在确定了执行任务安排后无需人工干预，因此完全执行模式也更适合不了解使用原理的新手用户。

## **3.6 支持配对模式与月度合成模式两种处理模式**

　　GeoThermoAI 使用的降尺度策略依赖 Sentinel-2 影像为 Landsat 地表温度数据提供空间细节，因此需要这两种卫星的影像形成配对，过境时间差小于等于 2 天且天气情况相似形成的真配对与月度合成影像形成的伪配对均可。因此 GeoThermoAI 提供面向真实精确地表热场景的配对模式和面向长时序月度地表热环境监测的配对模式，用户可以直接将配对模式或月度合成模式的要求包含在指令（用户提示词）中，由 GeoThermoAI 智能解析，当用户没有准确说明时，GeoThermoAI 将主动向用户提问。

　　GeoThermoAI 采样的月度合成算法为遥感领域常用的中值合成算法。

## **4.1 基础配置**

　　本小节介绍在正式使用 GeoThermoAI 生成 10m 地表温度产品之前需要完成的各项配置，包括 LLM 配置、数据源配置、连接测试、研究区配置与模型初始参数配置。这些配置均在进入对话后打开工作面板完成。工作面板由「API设置」「数据源」「测试」「研究区」「初始参数」「下载」「地图」「进度」「日志」「最终精度」等子页面组成，其中前五项为使用前需要确认的配置项，后五项用于查看任务进度与处理结果。

### **4.1.1 LLM API 配置**

　　进入 GeoThermoAI 页面后，打开工作面板并切换到「API设置」页面。首先选择 API 格式，系统支持 OpenAI Chat Completions 格式与 Anthropic Messages 格式，需根据所选模型厂商选择对应的兼容格式；然后在「请求地址」中填写模型的 Base URL（例如 [https://api.deepseek.com](https://api.deepseek.com)），系统会自动在末尾补全对应的接口路径；接着填写「模型 ID」与「API 密钥」。在「高级配置」中还可以设置「模型展示名称」与「上下文窗口」（上下文-输入、上下文-输出），上下文窗口应按所选模型的支持范围填写。相关配置方法可前往各模型厂商的开发平台查询。配置完成后点击「保存并应用」，模型即热更新生效。出于安全考虑，已保存的密钥不会以明文回显，而是显示为黑点占位；需要更换时重新输入即可覆盖原值。

　　我们推荐使用 DeepSeek V4 Flash，其最新的正式版已接入 API 且成本低廉能力强，性价比高。

### **4.1.2 数据源配置**

　　数据获取环节不需要用户手动上传原始影像，系统会自动从 Microsoft Planetary Computer 与 Copernicus Data Space 两个数据源检索并下载所需数据，具体分工为：Sentinel-2 L2A（多光谱与场景分类）优先使用 Copernicus Data Space，失败时自动回退 Microsoft Planetary Computer；Landsat 8/9 L2（地表温度与质量标识）使用 Microsoft Planetary Computer；DEM（Copernicus GLO-30）优先使用 Copernicus Data Space，需配置 S3 密钥，否则使用 Microsoft Planetary Computer。

　　考虑到国内直连国外数据服务的不便，建议在「数据源」页面填写 Copernicus Data Space 的注册账号与密码（在 dataspace.copernicus.eu 注册），以便优先使用国内访问更快的 Copernicus Data Space。在「高级配置」中还可填写 OAuth2 Client ID 与 Client Secret（用于影像搜索）以及 S3 Access Key 与 S3 Secret Key（DEM 走 Copernicus Data Space 下载时必需）。未配置或下载失败时，系统会自动回退 Microsoft Planetary Computer，不影响基本使用。

　　如果感觉 Copernicus Data Space 配置太复杂也没有关系，可以什么数据源都不配置，系统将自动回退到 Microsoft Planetary Computer 进行检索与下载，代价是国内虽可直连但比 Copernicus Data Space 下载更慢。

　　另外，无论采用何种数据源，我们都建议在本地 Docker 部署 GeoThermoAI 时开启代理达到更快的下载速度。

# **五、核心算法原理**

## **5.1 数据定标、对齐与掩膜**

### **5.1.1 Sentinel-2 反射率定标**

　　Sentinel-2 L2A 影像按场景元数据完成反射率转换：

```math
\rho_b=\frac{D_b+O_b}{Q}.
```

　　式中， $\rho_b$ 表示波段 $b$ 的地表反射率， $D_b$ 表示该波段的数字量化值， $O_b$ 表示场景元数据给出的加性偏移， $Q$ 表示量化因子， $b$ 表示具体光谱波段。无效的原始零值不参与后续计算。

### **5.1.2 Landsat 温度换算与质量控制**

　　Landsat 地表温度按产品规定的比例和偏移换算为开尔文：

```math
T=0.00341802D_T+149.0.
```

　　式中， $T$ 表示地表温度，单位为 K， $D_T$ 表示热红外温度波段的数字量化值。质量控制会排除填充值、云、卷云、膨胀云和云影。Sentinel-2 场景分类层仅保留植被、裸地和水体类别。连续变量使用双线性重采样，分类变量使用最近邻重采样。

## **5.2 光谱指数与地形特征**

　　系统利用光谱指数表达植被、水体和建成区差异：

```math
\mathrm{NDVI}=\frac{N-R}{N+R},\qquad
\mathrm{NDWI}=\frac{G-N}{G+N},\qquad
\mathrm{NDBI}=\frac{S-N}{S+N}.
```

　　式中， $N$ 表示近红外反射率， $R$ 表示红光反射率， $G$ 表示绿光反射率， $S$ 表示短波红外反射率。 $NDVI$ 、 $NDWI$ 和 $NDBI$ 分别用于描述植被、水体和建成区相关的光谱差异。

　　地形坡度和坡向由数字高程模型的水平梯度计算：

```math
\mathrm{Slope}=\frac{180}{\pi}\arctan\sqrt{g_x^2+g_y^2},
```

```math
\mathrm{Aspect}=\left[\frac{180}{\pi}\mathrm{atan2}(-g_x,g_y)+360\right]\bmod 360.
```

　　式中， $g_x$ 和 $g_y$ 分别表示高程在东西方向和南北方向的变化率， $\pi$ 为圆周率， $\mathrm{atan2}$ 为保留象限信息的反正切函数， $\bmod$ 表示取模运算。 $Slope$ 和 $Aspect$ 分别表示坡度与坡向，单位均为度。

## **5.3 双数据流与空间分块**

### **5.3.1 训练评估数据流**

　　训练评估数据流只保留同时通过温度、云掩膜、光谱和地形检查的 30m 样本。样本量较大时，行列方向均按固定步长抽样，避免相邻像元过度集中。随后按照空间块划分训练、验证和测试区域，并在不同集合边界设置空间缓冲带，以减少直接邻接造成的信息泄漏。具体缓冲距离作为实验设置在结果部分说明。

### **5.3.2 完整约束数据流**

　　完整约束数据流保留所有有效 30m 父格，用于地形热响应空间化、热约束校正和粗尺度闭合。它不被训练抽样替代。10m 有效区域由 Sentinel-2 有效光谱像元和场景分类共同确定，因此并非每个 10m 有效像元都拥有独立的 30m 热标签。

## **5.4 地形热响应指数**

　　由于没有开源的全球范围的 10m 地形数据，我们设计了地形热响应指数用于压缩高程、坡度和坡向对温度的综合影响并在 10m 尺度对地形数据进行替代。训练阶段拟合：

```math
T_{30}=\beta_0+aH+bS+c\cos A+\varepsilon.
```

　　式中， $T_{30}$ 表示 30 m 地表温度， $H$ 表示高程， $S$ 表示坡度， $A$ 表示坡向， $a$ 、 $b$ 和 $c$ 分别表示三类地形变量的回归系数， $\beta_0$ 表示截距， $\varepsilon$ 表示未被模型解释的残差。地形热响应指数定义为：

```math
I_{\mathrm{TTRI}}=aH+bS+c\cos A.
```

　　式中， $I_{\mathrm{TTRI}}$ 表示地形热响应指数，其余符号含义与上一式一致。各系数仅在训练集拟合一次，并保持不变地应用于验证区、测试区、完整 30m 约束格网和 10m 预测格网，从而避免利用验证区或测试区信息反向调整地形关系。

## **5.5 随机森林温度映射**

　　随机森林综合红、绿、蓝、近红外和短波红外反射率，以及 NDVI、NDWI、NDBI 和地形热响应指数，共九项特征。其预测结果表示为：

```math
\widehat{T}^{\mathrm{RF}}(\mathbf{x})=\frac{1}{M}\sum_{m=1}^{M}f_m(\mathbf{x}).
```

　　式中， $\widehat{T}^{\mathrm{RF}}$ 表示随机森林预测温度， $\mathbf{x}$ 表示九维输入特征向量， $M$ 表示回归树总数， $m$ 表示第 $m$ 棵树， $f_m$ 表示该树的预测函数。回归树数量和随机状态由实验配置确定，并在同一组训练、验证和测试过程中保持不变。

## **5.6 热约束残差校正**

　　随机森林初值具有 10m 空间细节，但同一 30m 父格内的细像元均值不一定等于热红外参考。对父格 $g$ ，先计算有效 10m 子像元的平均预测温度：

```math
\overline{T}^{\mathrm{RF}}_g=\frac{1}{n_g}\sum_{i\in g}\widehat{T}^{\mathrm{RF}}_i.
```

　　式中， $g$ 表示一个 30m 父格， $n_g$ 表示该父格内有效 10m 子像元数量， $i$ 表示其中一个子像元， $\widehat{T}^{\mathrm{RF}}_i$ 表示该子像元的随机森林预测温度， $\overline{T}^{\mathrm{RF}}_g$ 表示父格内的平均预测温度。

　　父格热约束残差为：

```math
R_g=T^{30}_g-\overline{T}^{\mathrm{RF}}_g.
```

　　式中， $R_g$ 表示父格 $g$ 的热约束残差， $T^{30}_g$ 表示该父格的 30m 参考温度。将同一残差加到父格内每个有效子像元，得到最终温度：

```math
\widehat{T}^{10}_i=\widehat{T}^{\mathrm{RF}}_i+R_g,\qquad i\in g.
```

　　式中， $\widehat{T}^{10}_i$ 表示子像元 $i$ 的最终 10m 温度，其余符号含义与前式一致。由此满足：

```math
\frac{1}{n_g}\sum_{i\in g}\widehat{T}^{10}_i=T^{30}_g.
```

　　这一等式表示匹配父格内的算术均值约束，不表示能量守恒，也不表示结果已经获得独立 10m 真值验证。

## **5.7 导出、评估与可选空洞填补**

　　最终产品以保留坐标参考、仿射变换和无效值信息的 GeoTIFF 输出。默认输出产物名称为 `rf_10m_lst_final.tif`。模型评价采用决定系数、均方根误差、平均绝对误差和平均偏差：

```math
R^2=1-\frac{\sum_{i=1}^{n}(y_i-\widehat{y}_i)^2}{\sum_{i=1}^{n}(y_i-\overline{y})^2},
```

```math
\mathrm{RMSE}=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(\widehat{y}_i-y_i)^2},
```

```math
\mathrm{MAE}=\frac{1}{n}\sum_{i=1}^{n}\left|\widehat{y}_i-y_i\right|,
\qquad
\mathrm{MB}=\frac{1}{n}\sum_{i=1}^{n}(\widehat{y}_i-y_i).
```

　　式中， $n$ 表示样本数量， $i$ 表示第 $i$ 个样本， $y_i$ 表示观测温度， $\widehat{y}_i$ 表示预测温度， $\overline{y}$ 表示全部观测温度的平均值。 $R^2$ 越接近 1 表示总体拟合越好， $RMSE$ 和 $MAE$ 越小表示误差越低， $MB$ 接近 0 表示总体系统偏差较小。

　　空洞较少时，系统采用距离加权方法补齐。空洞较多时，系统先在多尺度空间中估计，再恢复到原始分辨率。填充值用于连续显示，不参与热约束闭合或精度主张。

# **七、重要说明**

## **7.1 算法灵感**

　　GeoThermoAI 底层降尺度算法源自于前不久两位开发者的热红外遥感课程设计（中国地质大学（武汉）大三下学期课程），并非任何已公开发表的论文的研究成果，因此最终准确性有待验证，但根据我们的实践来看，其精度以及可信度较高，因此我们决定将它开源出来。

　　我们的算法灵感主要来源于以下论文和在线教程：

1. Kolláth, J., Kolláth, M., & Šveda, P. (2022). Combining Landsat 8 and Sentinel-2 data in Google Earth Engine to derive higher resolution land surface temperature maps in urban environment.*Remote Sensing* , 14(16), 4076. doi: 10.3390/rs14164076
2. Yuan, W., Hu, S., Zhan, C., Wang, G., & Luo, Y. (2025). Machine learning land surface temperature downscaling method based on Landsat 9 and Sentinel-2 satellite feature interaction.*Geo-spatial Information Science* , In Press. doi: 10.1080/10095020.2025.2598526
3. Bahi, H., Bounoua, L., Sabri, A., Bannari, A., Malah, A., & Rhinane, H. (2025). A new thermal fusion method to downscale land surface temperature to finer spatial resolution using Sentinel-MSI and Landsat-OLI/TIRS imagery.*Remote Sensing Applications: Society and Environment* , 37, 101519. doi: 10.1016/j.rsase.2025.101519
4. Andriambololonaharisoamalala, R. R., Helmholz, P., Bulatov, D., Ivanova, I., Song, Y., Soon, S., & Jones, E. (2025). Downscaling of urban land surface temperatures using geospatial machine learning with Landsat 8/9 and Sentinel-2 imagery.*Remote Sensing* , 17(14), 2392. doi: 10.3390/rs17142392
5. <https://mp.weixin.qq.com/s/OXwHyvUK3zEe0AoqTw6_rA>
