## 4. 第七阶段行为验收

1. 科学完成事务同时登记四个独立记忆目标，专项测试验证四条记录同一事务提交。
2. 记忆写回失败注入测试验证有限重试、指数退避、错误落库、任务结果不回滚和“结果已生成，经验保存待重试”日志。
3. 重启恢复测试验证 running 待办回收；达到最大次数的 running 待办变为 failed，不会永久卡住；低 R² 只跳过工作流，实验记录仍成功写回。
4. JSON 和 Chroma 稳定 ID upsert 测试验证重复写回只保留一条；中文项目名集合映射测试验证跨重启可复用。
5. LRU 加闲置 TTL 测试验证容量限制、真实过期和活动引用安全。
6. 旧对话和旧结果测试验证原始 ID、角色、正文保留，导入幂等；旧结果仅为 `legacy_unverified`，保留 `keep_forever` 引用但不登记科学成功、不生成记忆待办。
7. Docker 生命周期验证使用同一命名卷的新进程和新容器重开 schema v6，恢复任务、四路写回、向量和正式产物。
8. 配置验证覆盖非法预算、不可写路径、本机 SQLite 文件系统和 Docker `/app/data` 声明。
