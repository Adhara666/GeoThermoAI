1. 任务完成事务中登记四个互相独立的记忆写回待办：实验 JSON、实验向量、工作流 JSON、工作流向量。SQLite 台账仍是任务完成的唯一权威，记忆写回失败只进入 retry_wait 或 failed，不会回滚科学结果。
2. 新增后台投影执行器。领取、重试、错误、结果、完成时间均落库；采用有限指数退避，服务重启会回收 running 待办，达到上限的待办会明确终止，不会永久卡住。
3. 实验记录从状态内核、节点结果和正式产物血缘组装，稳定使用 `exp_run_<run_id>` 和 `wf_run_<run_id>`，JSON 和 Chroma 重复写回均为 upsert。工作流继续保留完整流程、评价结果和测试 R² 不低于 0.75 的原门槛。
4. 嵌入模型按模型目录共享，只读推理加锁；中文项目名映射到稳定的 Chroma 安全集合名，避免集合创建失败。
5. 新增容量和闲置时间双约束的 LRU 缓存，用户 Agent、记忆对象和目录搜索缓存均受配置限制；淘汰只释放缓存引用，不会使正在使用的对象失效。
6. 新增 `config/deployment.json` 和部署配置解析。账号、SQLite、记忆和小型元数据位于 `GTAI_DATA_ROOT`，大体量项目位于 `WORKSPACE_ROOT`，临时文件位于 `GTAI_TEMP_ROOT`。启动前检查可写性、SQLite 本机文件系统和所有预算数值。
7. Docker 默认声明 `/app/data` 持久卷，补齐 Docker 和 ModelScope 部署路径；旧账号、JWT 密钥、对话和结果引用采用幂等导入。证据不足的旧结果只登记为 `legacy_unverified`，不会伪造成成功运行或进入记忆。
8. 增加阶段七专项测试、武汉冻结输入回归脚本、持久化重开脚本以及可识别已提交节点产物布局的回归对比工具。
