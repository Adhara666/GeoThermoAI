第三方 Skill 开发指南

什么是 Skill？

Skill 是 GeoThermoAI 的核心扩展机制。每个 Skill 代表一个可被 AI 调用的独立功能模块。

什么是 group？

group 是 Skill 的分组标识。同组的 Skill 可以互相替换。例如：

  • 所有 group: "model_train_predict" 的 Skill 都是"模型训练与预测"步骤的候选实现
  • 系统默认使用内置 Random Forest 模型，你可以开发一个 XGBoost Skill（group 同样设为 model_train_predict），加载后系统就会使用你加载的模型

系统架构概述

GeoThermoAI 的降尺度处理流程为：数据获取 → 数据预处理 → TTRI 计算 → 模型训练与预测 → TCR 修正 → LST 导出 → 精度评估。

以下部分由系统内置实现，不可通过第三方 Skill 自定义或替换：

  • 数据获取：数据源固定为 Landsat 8/9（30m 地表温度）和 Sentinel-2（10m 多光谱），以及 Copernicus DEM（30m）
  • TTRI 计算：地形热响应指数，基于 DEM、坡度、坡向构建地形与温度的回归关系
  • TCR 修正：热约束残差，用于对模型预测结果进行物理一致性修正

可以开发什么 Skill？

  • 数据预处理类（group: data_process）：自定义云掩膜算法。系统内置 QA_PIXEL 和 SCL 云掩膜，你可以开发更精细的云检测方法（如基于机器学习的云识别、多时相云检测等）
  • 模型训练与预测类（group: model_train_predict）：替换训练算法（如 XGBoost、LightGBM、SVM、神经网络等）。注意：训练和预测在同一个 Skill 中完成，先训练模型，再用训练好的模型对测试集进行预测
  • LST 导出类（group: lst_export）：自定义输出格式和导出逻辑，如 GeoTIFF、NetCDF、HDF5、Cloud Optimized GeoTIFF 等
  • 精度评估类（group: accuracy_eval）：自定义评估指标和验证方法，如交叉验证、空间自相关分析等
  • AI 助手类（group: ai_assist）：扩展 AI 助手的能力，如添加新的对话技能、知识库查询等

模型训练与预测 Skill 的输入数据规范

开发模型训练与预测类 Skill 时，你的 execute 方法会收到包含 CSV 路径的 params 参数。CSV 文件中的列由上游数据预处理步骤生成，你必须按以下规范处理：

  • 特征列（9 列）：R、G、B、NIR、SWIR1、NDVI、NDWI、NDBI、TTRI
  • 标签列（1 列）：LST（地表温度，单位：开尔文 K）
  • 训练集 CSV：包含上述 9 个特征列 + LST 标签列，用于模型训练
  • 验证集 CSV：包含上述 9 个特征列 + LST 标签列，用于训练过程中的验证
  • 测试集 CSV：包含上述 9 个特征列 + LST 标签列，用于最终评估
  • 预测集 CSV：包含上述 9 个特征列，不含 LST 标签列（这是需要降尺度预测的 10m 分辨率数据）

你的模型 Skill 需要：

  • 读取训练集 CSV，用 9 个特征列训练模型，LST 列作为标签
  • 用验证集 CSV 评估训练效果
  • 用测试集 CSV 进行最终预测和评估
  • 保存模型文件，供后续 TCR 修正步骤使用

注意：TTRI 列由系统内置的 TTRI 计算步骤自动添加到 CSV 中，你的 Skill 无需自行计算 TTRI，直接使用即可。

开发规范

每个 Skill 必须继承 BaseSkill 基类，并实现以下抽象属性和方法：

from core.skills.base_skill import BaseSkill, SkillParameter, SkillResult

class MyCustomSkill(BaseSkill):
    @property
    def name(self) -> str:
        return "my_custom_skill"  # 唯一标识

    @property
    def group(self) -> str:
        return "data_process"  # 分组，同组可互换

    @property
    def description(self) -> str:
        return "自定义云掩膜算法"

    @property
    def parameters(self) -> list:
        return [
            SkillParameter("cloud_threshold", "number", "云概率阈值", required=False, default=0.5),
        ]

    @property
    def input_schema(self) -> dict:
        return {"image_path": "string"}

    @property
    def output_schema(self) -> dict:
        return {"masked_image_path": "string", "cloud_mask_path": "string"}

    def execute(self, params: dict, progress_callback=None, log_callback=None) -> SkillResult:
        # 核心逻辑
        return SkillResult(success=True, message="完成", data={...})

目录结构

skills/
  my_custom_skill/
    __init__.py      # 必须导出 Skill 类
    main.py          # 核心逻辑（可选）

打包与加载

将 Skill 文件夹打包为 .zip 文件，点击"加载第三方 Skill"按钮即可导入。系统会自动校验 Skill 是否符合规范。

注意事项

  • 同组 Skill 的 input_schema 和 output_schema 必须完全一致
  • Skill 的 execute 方法应支持进度回调和日志回调
  • 避免使用与内置 Skill 相同的 name
  • 模型训练与预测 Skill 必须处理 9 个特征列（R, G, B, NIR, SWIR1, NDVI, NDWI, NDBI, TTRI）和 1 个标签列（LST）
